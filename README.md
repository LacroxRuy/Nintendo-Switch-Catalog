# Nintendo Switch Catalog

Catálogo visual no oficial dedicado a Nintendo Switch.

## Secciones

- `ports.html` — Ports para Nintendo Switch modificada.
- `switch-games.html` — Lanzamientos recientes e imprescindibles de Nintendo Switch.
- `index.html` — Portada del sitio.

## Publicación con GitHub Pages

1. Subí estos archivos a un repositorio de GitHub.
2. Entrá en **Settings → Pages**.
3. En **Source**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/(root)`.
5. Guardá.

GitHub Pages detectará `index.html` como entrada del sitio.

## Aviso

Proyecto fan no oficial. No incluye ROMs, APKs, archivos comerciales ni contenido necesario para ejecutar juegos. Nintendo y las marcas de terceros pertenecen a sus respectivos propietarios.
